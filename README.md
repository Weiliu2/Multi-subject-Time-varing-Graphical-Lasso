The Python files and supplementary materials of Multi-subject Time-varying graphical lasso (msTVGL, or JUMP).

To msTVGL on a synthetic dataset, please run "TVGHADMMSolver.py".
"TVGLVisualizer.py" is the visualizer module of msTVGL.

To see the inspiration and mathematical derivation of msTVGL, please check Supplementary/Time varying graphical lasso for multiple subjects.pdf.
